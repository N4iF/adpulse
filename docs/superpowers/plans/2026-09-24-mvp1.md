# MVP-1 — Password Policy End to End — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** On the lab DC, one command scans the domain as a standard user, evaluates three password-policy checks, writes a scan result and static HTML reports in English and Arabic, and a second scan after the fix shows the findings resolved.

**Architecture:** `adsnap` reads the domain object over LDAPS and writes a snapshot (facts). `adrules` runs three YAML+Python rules through a small runner (judgement), diffs against the previous scan (new / open / resolved) and renders one static HTML report per language (EN and AR) with Jinja2. Contracts follow `docs/architecture.md` so later increments plug in without rework (D31).

**Tech Stack:** Python 3.12, uv, pydantic 2, ldap3, typer, PyYAML, Jinja2, pytest, ruff, mypy. PowerShell 5.1 on DC1 (VMware) for the one lab setup script.

**Where:** inside DC1, repo `C:\ADPulse\adpulse` (D30, D32). Commands are Windows PowerShell 5.1.

**Reference:** Tasks 1 and 3 below reuse code already written, unchanged, in
`docs/superpowers/plans/2026-09-23-phase1-engine.md` (the full-scope plan, now the reference for later

**Runner (Task 4).**
- A rule that lacks the data it needs raises `NotAssessed(reason)`; the runner returns `not_assessed`
  with that reason. Missing data never becomes a FAIL or a PASS.
- The privilege gate from the reference plan is kept: a `privilege_required: privileged` rule returns
  `needs_elevated` in standard mode (as `docs/architecture.md` states).

**Collector (Task 5).**
- An absent or empty policy attribute derives to `None`, not 0 / off. The collector then marks
  `directory_objects` as `partial` and adds an entry to `errors[]`; the PWD rules raise `NotAssessed`.
- `adsnap` gets a Typer callback so `adsnap collect --out …` is a real subcommand (a one-command Typer
  app otherwise swallows the name and exits 2); a CLI test covers it.
- `.env` loader: reads UTF-8 with or without BOM (UTF-16 is rejected with a clear message); `#` starts a
  comment at the start of a line or after whitespace in an unquoted value, so `Pass#word` survives and the
  documented inline comments work; a quoted value is taken as is; variables already set in the
  environment win.
- CA file: PEM or DER are both accepted (read the bytes and pass them to ldap3 as `ca_certs_data`);
  with `--insecure-lab` no CA file is loaded. A short connect timeout makes a dead DC fail fast.
- `collector.auth` is recorded as `simple` (the bind actually used).

**Scan and report (Task 6).**
- Lifecycle: the previous state is the previous scan's `new` and `open` lifecycle entries (including
  `not_reassessed` ones), not its raw results, so a finding stays `open` through any number of scans in
  which its rule could not run, and becomes `resolved` only when the rule runs again and passes.
- The previous scan is the latest saved scan of the same domain collected before this one; a scan whose
  snapshot id already exists is refused instead of overwritten.
- One `adrules scan` writes both reports, `<id>.en.html` and `<id>.ar.html` (no `--lang`), so the
  Arabic report is not a second scan.
- The report shows a per-check status table (passed / failed / not assessed with reason) and a coverage
  line; "All checks passed" appears only when every check passed.
- Evidence, remediation and the ECC limitation sentence are visible on screen and when printed (nothing
  hidden in a closed `<details>`); the limitation sentence is shown once near the top. Evidence is
  rendered generically (every key and value) so later rules with other evidence shapes still render.
  The mode label comes from `scan.mode`; severity labels are translated; a resolved row labels its value
  "last seen", not "current".
- CLI output is written as UTF-8 whatever the console code page (`adrules evaluate` prints Arabic).

```python
# packages/adsnap/src/adsnap/testing.py
"""Builders for mini-snapshots in tests. Nothing here comes from a real domain."""

from __future__ import annotations

from datetime import UTC, datetime
from typing import Any

from adsnap.model import ADObject, CollectorInfo, CoverageLevel, DomainInfo, ObjectType, Snapshot, SnapshotMeta

DOMAIN_SID = "S-1-5-21-1-2-3"
DOMAIN_DN = "DC=corp,DC=local"
COLLECTED_AT = datetime(2026, 10, 1, tzinfo=UTC)
DEFAULT_COVERAGE: dict[str, CoverageLevel] = {"directory_objects": CoverageLevel.FULL}


def make_domain(**derived: Any) -> ADObject:
    d: dict[str, Any] = {"min_password_length": 14, "password_complexity": True, "lockout_threshold": 5}
    d.update(derived)
    return ADObject(object_id="guid-domain", object_type=ObjectType.DOMAIN, dn=DOMAIN_DN, name="corp.local", object_sid=DOMAIN_SID, derived=d)


def make_snapshot(*objects: ADObject, coverage: dict[str, CoverageLevel] | None = None, collected_at: datetime = COLLECTED_AT) -> Snapshot:
    objs = list(objects)
    if not any(o.object_type is ObjectType.DOMAIN for o in objs):
        objs.insert(0, make_domain())
    cov = dict(DEFAULT_COVERAGE)
    cov.update(coverage or {})
    meta = SnapshotMeta(
        id=f"{collected_at:%Y%m%dT%H%M%SZ}-corp.local",
        collected_at=collected_at,
        collector=CollectorInfo(name="adsnap-test", version="0"),
        domain=DomainInfo(object_id="guid-domain", dn=DOMAIN_DN, netbios="CORP", sid=DOMAIN_SID),
    )
    return Snapshot(snapshot=meta, objects=objs, coverage=cov)
```

```python
# packages/adrules/src/adrules/catalog/__init__.py
"""Rule catalog: YAML metadata + Python evaluate(); coverage gate; runner (D31 contract)."""

from __future__ import annotations

import importlib
import importlib.resources
from collections.abc import Callable
from dataclasses import dataclass
from typing import Any, Literal

import yaml
from adsnap.model import COVERAGE_KEYS, ADObject, CoverageLevel, Snapshot
from pydantic import BaseModel, Field, field_validator

from adrules.finding import CheckResult, Confidence, Finding, Localized, Severity, Status


class RuleMeta(BaseModel):
    id: str
    category: str
    severity: Severity
    privilege_required: Literal["standard", "privileged"] = "standard"
    requires_coverage: list[str]
    title: Localized
    why_it_matters: Localized
    remediation: Localized
    control_mappings: dict[str, list[str]] = Field(default_factory=dict)
    attack_techniques: list[str] = Field(default_factory=list)
    matches_pingcastle_rule: str | None = None
    evidence_source: str
    params: dict[str, Any] = Field(default_factory=dict)

    @field_validator("requires_coverage")
    @classmethod
    def _known(cls, keys: list[str]) -> list[str]:
        unknown = [k for k in keys if k not in COVERAGE_KEYS]
        if unknown:
            raise ValueError(f"unknown coverage keys {unknown}")
        return keys


@dataclass(frozen=True)
class RuleContext:
    mode: str  # "standard" | "privileged"


Evaluator = Callable[[Snapshot, RuleMeta, RuleContext], list[Finding]]


@dataclass(frozen=True)
class Rule:
    meta: RuleMeta
    evaluate: Evaluator


def finding(meta: RuleMeta, obj: ADObject, evidence: dict[str, Any], *, confidence: Confidence = "high") -> Finding:
    return Finding(
        rule_id=meta.id, category=meta.category, severity=meta.severity,
        title=meta.title, why_it_matters=meta.why_it_matters, remediation=meta.remediation,
        affected_object=obj.object_id, affected_object_type=obj.object_type, affected_name=obj.name,
        evidence=evidence, evidence_source=meta.evidence_source,
        control_mappings=meta.control_mappings, attack_techniques=meta.attack_techniques, confidence=confidence,
    )


def load_catalog() -> list[Rule]:
    rules: list[Rule] = []
    for entry in importlib.resources.files("adrules.catalog").iterdir():
        if entry.name.endswith(".yaml"):
            meta = RuleMeta.model_validate(yaml.safe_load(entry.read_text(encoding="utf-8")))
            module = importlib.import_module(f"adrules.catalog.{entry.name[:-5]}")
            rules.append(Rule(meta=meta, evaluate=module.evaluate))
    return sorted(rules, key=lambda r: r.meta.id)


def run_rule(rule: Rule, snapshot: Snapshot, ctx: RuleContext) -> CheckResult:
    meta = rule.meta
    missing = [k for k in meta.requires_coverage if snapshot.coverage_of(k) is CoverageLevel.NONE]
    if missing:
        return CheckResult(rule_id=meta.id, status=Status.NOT_ASSESSED, reason=f"coverage {', '.join(missing)} is none")
    partial = any(snapshot.coverage_of(k) is CoverageLevel.PARTIAL for k in meta.requires_coverage)
    confidence: Confidence = "medium" if partial else "high"
    findings = rule.evaluate(snapshot, meta, ctx)
    if partial:
        findings = [f.model_copy(update={"confidence": "medium"}) for f in findings]
    return CheckResult(rule_id=meta.id, status=Status.FAIL if findings else Status.PASS, confidence=confidence, findings=findings)


def run_all(snapshot: Snapshot, rules: list[Rule] | None = None) -> list[CheckResult]:
    ctx = RuleContext(mode=snapshot.snapshot.collector.mode)
    return [run_rule(r, snapshot, ctx) for r in (rules if rules is not None else load_catalog())]
```

```python
# packages/adrules/src/adrules/catalog/pwd_01.py
"""PWD-01: domain minimum password length below params.min_length."""

from adsnap.model import Snapshot

from adrules.catalog import RuleContext, RuleMeta, finding
from adrules.finding import Finding


def evaluate(snapshot: Snapshot, meta: RuleMeta, ctx: RuleContext) -> list[Finding]:
    domain = snapshot.domain()
    minimum = int(meta.params.get("min_length", 12))
    length = domain.derived.get("min_password_length")
    if length is None or int(length) >= minimum:
        return []
    return [finding(meta, domain, {"setting": "minPwdLength", "current": int(length), "expected": f">= {minimum}"})]
```

```python
# packages/adsnap/src/adsnap/derive.py
"""Raw LDAP attributes -> derived fields (collector/rules contract, docs/architecture.md)."""

from __future__ import annotations

from collections.abc import Mapping
from typing import Any

DOMAIN_PASSWORD_COMPLEX = 0x1


def _int(v: Any) -> int:
    v = v[0] if isinstance(v, list) and v else v
    return int(v) if v not in (None, "", []) else 0


def derive_domain(raw: Mapping[str, Any]) -> dict[str, Any]:
    return {
        "min_password_length": _int(raw.get("minPwdLength")),
        "password_complexity": bool(_int(raw.get("pwdProperties")) & DOMAIN_PASSWORD_COMPLEX),
        "lockout_threshold": _int(raw.get("lockoutThreshold")),
    }
```

```python
# packages/adsnap/src/adsnap/ldap.py
"""Read the domain object over LDAPS with ldap3 (standard user, simple bind with UPN over TLS)."""

from __future__ import annotations

import ssl
from typing import Any, Protocol

from ldap3 import ALL, BASE, SIMPLE, Connection, Server, Tls

DOMAIN_ATTRIBUTES = ["objectGUID", "objectSid", "name", "minPwdLength", "pwdProperties", "lockoutThreshold"]


class DomainSource(Protocol):
    def read_domain(self) -> dict[str, Any]: ...


class Ldap3DomainSource:
    def __init__(self, host: str, user: str, password: str, *, ca_cert: str | None = None, insecure_lab: bool = False) -> None:
        tls = Tls(validate=ssl.CERT_NONE if insecure_lab else ssl.CERT_REQUIRED, ca_certs_file=ca_cert)
        self._server = Server(host, port=636, use_ssl=True, tls=tls, get_info=ALL)  # schema: GUID/SID arrive as text
        self._conn = Connection(self._server, user=user, password=password, authentication=SIMPLE, auto_bind=True, raise_exceptions=True)

    def read_domain(self) -> dict[str, Any]:
        base = str(self._server.info.other["defaultNamingContext"][0])
        self._conn.search(base, "(objectClass=domainDNS)", search_scope=BASE, attributes=DOMAIN_ATTRIBUTES)
        entry = self._conn.response[0]
        return {"dn": entry["dn"], **entry["attributes"]}
```

```python
# packages/adsnap/src/adsnap/collector.py
"""Collect a Snapshot of the domain object. Facts only; raises if the directory cannot be read."""

from __future__ import annotations

from datetime import UTC, datetime

from adsnap import __version__
from adsnap.derive import derive_domain
from adsnap.ldap import DomainSource
from adsnap.model import ADObject, CollectorInfo, CoverageLevel, DomainInfo, ObjectType, Snapshot, SnapshotMeta


def _first(v):  # ldap3 may return single values as one-item lists
    return v[0] if isinstance(v, list) and len(v) == 1 else v


def collect(source: DomainSource, *, now: datetime | None = None, domain_dns: str = "", mode: str = "standard") -> Snapshot:
    now = now or datetime.now(UTC)
    row = source.read_domain()
    domain = ADObject(
        object_id=str(_first(row["objectGUID"])).strip("{}").lower(),
        object_type=ObjectType.DOMAIN,
        dn=row["dn"],
        name=domain_dns or str(_first(row.get("name"))),
        object_sid=str(_first(row["objectSid"])),
        raw={k: _first(v) for k, v in row.items() if k in ("minPwdLength", "pwdProperties", "lockoutThreshold")},
        derived=derive_domain(row),
    )
    meta = SnapshotMeta(
        id=f"{now:%Y%m%dT%H%M%SZ}-{domain.name}",
        collected_at=now,
        collector=CollectorInfo(name="adsnap", version=__version__, mode=mode),  # type: ignore[arg-type]
        domain=DomainInfo(object_id=domain.object_id, dn=domain.dn, netbios=domain.name.split(".")[0].upper(), sid=domain.object_sid or ""),
    )
    return Snapshot(snapshot=meta, objects=[domain], coverage={"directory_objects": CoverageLevel.FULL})
```

```python
# packages/adsnap/src/adsnap/cli.py
"""adsnap: collect a snapshot (reads settings from .env in the current folder)."""

from __future__ import annotations

import os
from pathlib import Path

import typer

from adsnap.model import Snapshot

app = typer.Typer(help="ADPulse snapshot collector", no_args_is_help=True)


def load_dotenv(path: Path = Path(".env")) -> None:
    if not path.exists():
        return
    for line in path.read_text(encoding="utf-8").splitlines():
        line = line.split("#", 1)[0].strip()
        if "=" in line:
            key, value = line.split("=", 1)
            os.environ.setdefault(key.strip(), value.strip())


def collect_from_env(insecure_lab: bool = False) -> Snapshot:
    from adsnap.collector import collect
    from adsnap.ldap import Ldap3DomainSource

    load_dotenv()
    env = os.environ
    missing = [k for k in ("ADPULSE_DC", "ADPULSE_DOMAIN", "ADPULSE_USER", "ADPULSE_PASSWORD") if not env.get(k)]
    if missing:
        raise typer.BadParameter(f"set {', '.join(missing)} in .env (see docs/SETUP.md)")
    source = Ldap3DomainSource(env["ADPULSE_DC"], env["ADPULSE_USER"], env["ADPULSE_PASSWORD"], ca_cert=env.get("ADPULSE_CA_CERT"), insecure_lab=insecure_lab)
    return collect(source, domain_dns=env["ADPULSE_DOMAIN"], mode=env.get("ADPULSE_MODE", "standard"))


@app.command()
def collect(
    out: Path = typer.Option(..., "--out", help="where to write the snapshot JSON"),
    insecure_lab: bool = typer.Option(False, "--insecure-lab", help="skip TLS validation (lab only)"),
) -> None:
    snap = collect_from_env(insecure_lab)
    out.parent.mkdir(parents=True, exist_ok=True)
    out.write_text(snap.model_dump_json(indent=2), encoding="utf-8")
    typer.echo(f"snapshot {snap.snapshot.id} -> {out}")
```

```python
# packages/adrules/src/adrules/scan.py
"""ScanResult, the lifecycle diff between two scans, and scan storage (docs/architecture.md)."""

from __future__ import annotations

from datetime import datetime
from pathlib import Path
from typing import Literal

from adsnap.model import CoverageLevel, Snapshot
from pydantic import BaseModel, Field

from adrules.finding import CheckResult, Finding, Status

SCHEMA_VERSION = "1.0"


class LifecycleEntry(BaseModel):
    key: str
    state: Literal["new", "open", "resolved"]
    not_reassessed: bool = False
    finding: Finding


class ScanResult(BaseModel):
    schema_version: str = SCHEMA_VERSION
    snapshot_id: str
    collected_at: datetime
    domain: str
    mode: str
    coverage: dict[str, CoverageLevel]
    results: list[CheckResult]
    lifecycle: list[LifecycleEntry] = Field(default_factory=list)
    previous_scan_id: str | None = None

    def count(self, state: str) -> int:
        return sum(1 for e in self.lifecycle if e.state == state)

    def failed(self) -> int:
        return sum(1 for r in self.results if r.status is Status.FAIL)


def finding_key(f: Finding) -> str:
    return "|".join([f.rule_id, f.affected_object, f.subject_id or ""])


def diff(previous: ScanResult | None, results: list[CheckResult]) -> list[LifecycleEntry]:
    current = {finding_key(f): f for r in results for f in r.findings}
    before = {finding_key(f): f for r in (previous.results if previous else []) for f in r.findings}
    reassessed = {r.rule_id for r in results if r.status in (Status.PASS, Status.FAIL)}
    out = [LifecycleEntry(key=k, state="open" if k in before else "new", finding=f) for k, f in current.items()]
    for k, f in before.items():
        if k not in current:
            if f.rule_id in reassessed:
                out.append(LifecycleEntry(key=k, state="resolved", finding=f))
            else:  # the rule could not run this time: never claim "resolved"
                out.append(LifecycleEntry(key=k, state="open", not_reassessed=True, finding=f))
    return out


def build_scan(snapshot: Snapshot, results: list[CheckResult], previous: ScanResult | None) -> ScanResult:
    meta = snapshot.snapshot
    return ScanResult(
        snapshot_id=meta.id, collected_at=meta.collected_at, domain=snapshot.domain().name, mode=meta.collector.mode,
        coverage=snapshot.coverage, results=results, lifecycle=diff(previous, results),
        previous_scan_id=previous.snapshot_id if previous else None,
    )


def load_scans(folder: Path) -> list[ScanResult]:
    if not folder.exists():
        return []
    scans = [ScanResult.model_validate_json(p.read_text(encoding="utf-8")) for p in folder.glob("*.scan.json")]
    return sorted(scans, key=lambda s: s.collected_at)


def save_scan(scan: ScanResult, folder: Path) -> Path:
    folder.mkdir(parents=True, exist_ok=True)
    path = folder / f"{scan.snapshot_id}.scan.json"
    path.write_text(scan.model_dump_json(indent=2), encoding="utf-8")
    return path
```

```python
"""adrules: evaluate a snapshot, or run a full scan (collect → rules → diff → HTML report)."""

from __future__ import annotations

import json
from pathlib import Path

import typer
from adsnap.model import Snapshot

from adrules.catalog import run_all
from adrules.report import render_report
from adrules.scan import build_scan, load_scans, save_scan

app = typer.Typer(help="ADPulse rules engine", no_args_is_help=True)


@app.command()
def evaluate(snapshot: Path = typer.Argument(..., exists=True)) -> None:
    snap = Snapshot.model_validate_json(snapshot.read_text(encoding="utf-8"))
    typer.echo(json.dumps([r.model_dump(mode="json") for r in run_all(snap)], ensure_ascii=False, indent=2))


@app.command()
def scan(
    out_dir: Path = typer.Option(Path("snapshots"), "--out-dir", help="scan results and reports (git-ignored)"),
    lang: str = typer.Option("en", "--lang", help="report language: en or ar"),
    from_snapshot: Path | None = typer.Option(None, "--from-snapshot", help="use a saved snapshot instead of collecting"),
    insecure_lab: bool = typer.Option(False, "--insecure-lab", help="skip TLS validation (lab only)"),
) -> None:
    if lang not in ("en", "ar"):
        raise typer.BadParameter("--lang must be en or ar")
    if from_snapshot:
        snap = Snapshot.model_validate_json(from_snapshot.read_text(encoding="utf-8"))
    else:
        from adsnap.cli import collect_from_env

        snap = collect_from_env(insecure_lab)
    history = load_scans(out_dir)
    result = build_scan(snap, run_all(snap), history[-1] if history else None)
    save_scan(result, out_dir)
    report = out_dir / f"{result.snapshot_id}.{lang}.html"
    report.write_text(render_report(result, [*history, result], lang), encoding="utf-8")
    typer.echo(
        f"{len(result.results)} checks: {result.failed()} failed | new {result.count('new')}, "
        f"open {result.count('open')}, resolved {result.count('resolved')} -> {report}"
    )
```

```python
# packages/adrules/tests/test_lab_truth_table.py
from pathlib import Path

import pytest
import yaml
from adsnap.model import Snapshot

from adrules.catalog import run_all
from adrules.finding import Status

FIX = Path(__file__).parent / "fixtures"
TRUTH = yaml.safe_load((Path(__file__).resolve().parents[3] / "lab" / "expected-findings.yaml").read_text(encoding="utf-8"))["mvp1"]


@pytest.mark.parametrize(("fixture", "expected"), [("lab-default.json", "default_domain"), ("lab-fixed.json", "after_fix")])
def test_lab_matches_ground_truth(fixture, expected):
    path = FIX / fixture
    if not path.exists():
        pytest.skip(f"record {fixture} on DC1 first (Task 8)")
    snap = Snapshot.model_validate_json(path.read_text(encoding="utf-8"))
    failed = sorted(r.rule_id for r in run_all(snap) if r.status is Status.FAIL)
    assert failed == sorted(TRUTH[expected])
```
